          Run a set of jobs and compare each with its pinned baseline. A gate fails if a job fails, a measure that was
          in range is out of range, or fewer measures are in range than in the baseline. Pin baselines from a passing
          gate, or from any run's detail on the Run tab.

          Try values of one tuning constant: the job runs with the game's own value first, then with each value you
          give, on the same seeds, and the table shows which measures each value moves and how many stay in range.
          Constants are the capitalised numbers the game exposes (Season.LEARN.step,
          Transfers.HOME_SCALE …); a run reads them at the start and the source is not touched.

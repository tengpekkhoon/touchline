Calibrate against ratings you trust

        

          Give the converter players whose ability you already know (another game's ratings, a scouting service, your
          own judgement) in an expected column, on the same 1–100 scale as the game's ability. It shows how
          far off it is, where it is biased by position group, and the offset and spread that would fit best (RS.TUNE
          in js/realstats.js).

Map a messy file

        

          Real datasets rarely arrive with the importer's column names. Load any CSV (comma, semicolon or tab), say what
          it is, check the suggested mapping, match its club names to the base world's clubs, and get a file in the
          importer's format.
        

        

          

            
            
            
            
          

          
          

        

        

        

        

        
Check a world definition

        

          

            
          

          

        

      


      
      

        

          Run a set of jobs and compare each with its pinned baseline. A gate fails if a job fails, a measure that was
          in range is out of range, or fewer measures are in range than in the baseline. Pin baselines from a passing
          gate, or from any run's detail on the Run tab.
        

        

          docs, lint, format, converter, world definition, importer, 1-season suite
          adds regression test, 3-season suite, calibration, wonderkids, transfers (about 30–40 minutes)
        

        

          

            
Recent gates

            

          

          

            
Baselines

            

          

        

        

      


      
      

        

          One measure across every run of a job: the real range as a band, the runs as points. Slow drift shows here
          when no single run looks wrong.
        

        

          
          
          
          
        

        

      


      
      

        

          The same job on several seeds at once, as one table: the mean, the spread and how many seeds put each measure
          in range. Use it to tell a real change from seed noise.
        

        

          
          
          
          
        

        

          

            
Recent matrices

            

          

          

        

        

      


      
      

        

          Try values of one tuning constant: the job runs with the game's own value first, then with each value you
          give, on the same seeds, and the table shows which measures each value moves and how many stay in range.
          Constants are the capitalised numbers the game exposes (Season.LEARN.step,
          Transfers.HOME_SCALE …); a run reads them at the start and the source is not touched.
